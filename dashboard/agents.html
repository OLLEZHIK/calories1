Спецификация и статус 6 ИИ-Агентов

Все 6 агентов работают автономно в цепочке конвейера (Pipeline)

★ TeamLeadAgent ACTIVE
Тимлид & Менеджер. Принимает ваши задачи на фичи (например, 'добавь сожженные калории') и расписывает таски агентам.
Ввод: Запрос на фичу → Вывод: Таски для Агентов
🎙 AudioAgent ACTIVE
Агент-расшифровщик речи. Бесплатно распознает голосовые сообщения Telegram в русский текст БЕЗ платных API-ключей.
Ввод: Аудио заметок → Вывод: Распознанный текст
1. IngestionAgent ACTIVE
Парсит сырой ввод (текст, надиктованный голос, фото) и находит продукты, граммовку и указанные цены (€ / руб).
Ввод: Текст / Голос → Вывод: JSON продукты
2. NutritionAgent ACTIVE
Вычисляет калории, белки, жиры и углеводы. Запрашивает локальную БД или Open Food Facts API при редких продуктах.
Ввод: Продукт + граммы → Вывод: БЖУ / 100г
3. AuditorAgent ACTIVE
Аудитор точности. Проверяет равенство калорий энергетической формуле (4P + 9F + 4C) и корректирует сбои.
Ввод: Считанные БЖУ → Вывод: Проверенные БЖУ
4. EconomyAgent ACTIVE
Отслеживает стоимости упаковок, считает цену за 100г и стоимость 100г белков/углеводов в приеме пищи.
Ввод: Цена за вес → Вывод: Стоимость БЖУ
5. CoachAgent ACTIVE
Личный ИИ-тренер. Анализирует вредные источники жиров (майонез), избыток калорий и дает персональные рекомендации.
Ввод: Статистика дня → Вывод: Советы диетолога
6. DashboardAgent ACTIVE
Связывает результаты работы всех агентов и синхронизирует онлайн-дашборд и Supabase в реальном времени.
Ввод: Итоги агентов → Вывод: Живой Дашборд
